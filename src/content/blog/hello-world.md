(the filename becomes the URL, e.g. `my-post.md` → `/blog/my-post`), and
edit the frontmatter block above.

## Writing

You write in plain **Markdown**. Headings, lists, links, `code`, and images
all work out of the box.

```js
// Fenced code blocks get syntax highlighting automatically.
const hi = (name) => `hello, ${name}`;
```

Set `draft: true` in the frontmatter to hide a post until it's ready — drafts
never show up in the list or get built.

That's the whole workflow: add a `.md` file, push, and it's live.
